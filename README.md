# LeetCode 283. 移动零 - 算法可视化

这是 LeetCode 第 283 题「移动零」的算法可视化演示项目。

通过分步动画帮助理解双指针算法的执行过程。

## 在线演示

👉 [点击访问](https://fuck-algorithm.github.io/leetcode-283-move-zeroes/)

## 功能特点

- 🎯 分步动画演示算法执行过程
- 💻 支持 Java、Python、Go、JavaScript 四种语言代码展示
- 🎮 键盘快捷键控制（方向键、空格、R）
- 📊 可拖拽的进度条
- 🔍 支持自定义输入数据

## 本地开发

```bash
npm install --legacy-peer-deps
npm start
```
